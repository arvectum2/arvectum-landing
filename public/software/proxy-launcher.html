Arvectum Proxy Launcher 0.2.9

Локальное кроссплатформенное приложение для управления системными proxy/PAC-настройками рабочего места, локальными HTTP/SOCKS5 endpoint'ами и безопасного восстановления исходной сетевой конфигурации.

Эта страница содержит функциональные характеристики и сведения, необходимые для установки и эксплуатации версии 0.2.9. Она не является заявлением о включении продукта в Единый реестр российского программного обеспечения.

Назначение и функциональные характеристики

Proxy Launcher централизует включение, отключение и восстановление пользовательских системных proxy-настроек при работе через внешний proxy-сервер, предоставленный пользователем или заказчиком.

  • управление системным proxy/PAC и bypass/no_proxy;
  • локальные HTTP и SOCKS5 endpoint'ы для клиентских приложений;
  • сохранение исходного состояния управляемых сетевых параметров;
  • штатный rollback при отключении;
  • восстановление после сбоя или перезагрузки;
  • защита от разрушительного восстановления при обнаружении стороннего изменения: неизвестное третье значение не перезаписывается автоматически.

Продукт является локальным desktop-приложением. Он не является VPN, маршрутизатором, межсетевым экраном, сертифицированным средством защиты информации или облачным сервисом. Внешний upstream proxy не входит в поставку Proxy Launcher.

Поддерживаемые операционные системы

  • Microsoft Windows x64 — Setup и portable;
  • Astra Linux 1.8 x86-64 / Fly — пакет DEB;
  • РЕД ОС 8.0.3 x86-64 / KDE Plasma — пакет RPM.

Для Linux требуется NetworkManager и штатная desktop-интеграция целевой системы. Для установки системного пакета нужны административные права.

Установка и запуск

Windows x64

Запустите Arvectum-Proxy-Launcher-0.2.9-windows-x64-setup.exe и завершите установку для текущего пользователя. Альтернативно можно распаковать portable ZIP и запустить приложение из него. Версия 0.2.9 не заявляет Authenticode-подпись; отключать Defender, SmartScreen или firewall для установки не требуется.

Astra Linux 1.8 x86-64

sudo apt install ./Arvectum-Proxy-Launcher-0.2.9-astra-linux-amd64.deb
arvectum-proxy-launcher

Целевая среда использует NetworkManager и GSettings для desktop proxy integration.

РЕД ОС 8.0.3 x86-64

sudo dnf install ./Arvectum-Proxy-Launcher-0.2.9-redos-linux-x86_64.rpm
arvectum-proxy-launcher

Эксплуатация

  1. Запустите Proxy Launcher.
  2. Укажите параметры внешнего upstream proxy, разрешённого вашей организацией или предоставленного вашим провайдером.
  3. Проверьте bypass/no_proxy исключения.
  4. Включите Proxy Launcher.
  5. Убедитесь, что системный proxy/PAC и локальный endpoint отражают ожидаемую конфигурацию, затем проверьте целевое приложение.
  6. Для завершения работы используйте штатное отключение и убедитесь, что исходные сетевые параметры восстановлены.

Аварийное восстановление

Перед изменением управляемых параметров Proxy Launcher сохраняет доказуемое исходное состояние. После сбоя или перезапуска recovery восстанавливает только значения, которые распознаются как исходные или ранее применённые самим приложением. Если пользователь или администратор установил третье значение, destructive rollback прекращается вместо автоматической перезаписи неизвестного состояния.

При незавершённом recovery не удаляйте вручную данные восстановления. Сначала завершите штатное восстановление, затем обновляйте или удаляйте приложение.

Удаление

Перед удалением штатно отключите активный proxy lifecycle и убедитесь, что исходная конфигурация восстановлена. На Windows используйте стандартное удаление установленного приложения. На Astra Linux и РЕД ОС удалите установленный пакет штатным менеджером пакетов после завершения rollback/recovery.
